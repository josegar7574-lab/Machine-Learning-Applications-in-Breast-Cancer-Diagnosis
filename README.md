# Senior Research Project   

I'm looking into how machine learning can help detect breast cancer. Throughout the project, I'll test several algorithms to see how accurately and efficiently they can identify breast cancer cases.

## Objectives 
- Explore different machine learning algorithms used in breast cancer diagnosis
- Examine how efficiently and accurately each algorithms detect breast cancer.
- Compare algorithms performance using accuracy, precision, recall, and AUC

### Algorithms
The following algorithms I will be using are:
- Logistic Regresion
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)

#### Tools and Dataset
- Python
- Winsoncin Breast Cancer Diagnositc Dataset
